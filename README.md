# Учёт заказов фабрики

Веб-приложение на Next.js (App Router) + Supabase для учёта клиентов, товаров и заказов производства.

## Экраны

- `/clients` — список и добавление клиентов
- `/products` — список и добавление товаров
- `/orders/new` — создание заказа (клиент + список товаров)
- `/orders` — список заказов со статусами: новый, подтверждён, в производстве, отгружен, оплачен
- `/orders/[id]` — детали заказа и смена статуса
- `/analytics` — аналитика: выручка, заказы по статусам, выручка по месяцам, топ клиентов и товаров

## Запуск локально

1. Установите Node.js 18+ (https://nodejs.org).
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте проект на https://supabase.com, откройте **SQL Editor** и выполните файл `supabase/schema.sql` целиком.
4. Скопируйте `.env.local.example` в `.env.local` и вставьте URL и anon key вашего проекта Supabase (**Project Settings → API**):

   ```bash
   cp .env.local.example .env.local
   ```

5. Запустите dev-сервер:

   ```bash
   npm run dev
   ```

6. Откройте http://localhost:3000

## Важно про безопасность

Политики Row Level Security в `supabase/schema.sql` открывают полный доступ по anon-ключу (без входа в систему) — это подходит для внутреннего инструмента фабрики без публичного доступа. Если приложение станет доступно извне или потребуется вход по логину, добавьте Supabase Auth и ограничьте политики проверками `auth.uid()`.

## Валюта

По умолчанию суммы форматируются в рублях (`lib/format.ts`, функция `formatMoney`). При необходимости поменяйте код валюты там же.
